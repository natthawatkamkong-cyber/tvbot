# Secure setup\n\n1. Revoke the old Telegram bot token via BotFather. Git history may still contain the old token; rotation is mandatory.\n2. Set TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID and a long random WEBHOOK_SECRET as environment variables on the hosting service. Never commit real values.\n3. Configure the TradingView/n8n webhook to send header X-Webhook-Secret matching WEBHOOK_SECRET.\n4. Deploy from this branch only after reviewing the pull request and verifying compatibility.\n5. Test /health and POST /webhook with invalid secret (must return 401), then a valid secret (must send Telegram).\n6. Do not enable automated order execution.\n\nNote: This is a security patch, not a deployed or tested production system.\n
